# F0-18 — matrix runner report (fix 6)

## What changed

### 1. The base prompt reaches the agent

- `factory/adapters/prompt.py`: new `render_prompt(task: str, workdir: str) -> str`.
  It substitutes `{{ task }}` and `{{ workdir }}` in `prompt_text()` and raises
  `ValueError` for any other placeholder left in the template. `prompt_sha()`
  still hashes `prompts/base-v1.md` byte for byte.
- `factory/tasks/to_harbor.py`: `instruction.md` is now
  `render_prompt(<proposal + specs>, workdir_of(task))`. The agent finally sees
  the read-only-tests / no-network / no-useful-history / abort-channel rules and
  the `AGENTS.md` / `CLAUDE.md` note, while the run documents keep recording the
  template hash.
- `prompts/base-v1.md`: every literal `/workspace` was replaced by
  `{{ workdir }}` (repository path, working-directory rule and abort path). No
  other wording changed.

### 2. The abort channel follows `repo.workdir`

- `factory/adapters/abort.py`: `abort_path_for(workdir)` returns
  `<workdir>/.factory/abort.json`. `read_abort(workspace)` keeps its old default
  (`/workspace/.factory/abort.json`), and a new keyword `workdir=` selects the
  task directory; containment checks are relative to that workdir instead of a
  fixed `/workspace`.
- `factory/run_matrix.py`: the executor input document carries
  `abort_path = abort_path_for(workdir_of(task))`, so an executor reading the
  contract is pointed at `/testbed/.factory/abort.json` for a `/testbed` task.
  Nothing in `run_matrix` read the abort document itself; only the input contract
  had a fixed default path.

## Tests

  `ValueError`; `prompt_sha` still hashes the template file.
- `tests/tasks/test_to_harbor.py`: with `repo.workdir = /testbed`, the
  `instruction.md` starts with the rendered prompt header, contains the task
  text, contains `/testbed/.factory/abort.json` and has no `/workspace`.
- `tests/tasks/test_import_hf.py`: the instruction still contains the generated

- `tests/adapters/test_abort.py`: `read_abort(..., workdir="/testbed")` reads the
  abort document from the task workdir.
- `tests/run_matrix/test_run_matrix.py`: the input document for a `/testbed` task
  declares `/testbed/.factory/abort.json`.
