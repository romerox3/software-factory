# F0-18 — matrix runner report (fix 1)

## What changed

The matrix runner now produces Harbor tasks a real run can use. Existing default
behaviour is preserved except for the diff export, which is now always emitted.

- `factory/tasks/to_harbor.py`
  - `to_harbor(visible_task_dir, out_dir, *, executor=None, allowed_hosts=())`.
  - `executor` appends `factory.adapters.config.image_snippet(executor)` to the
    Dockerfile, after the snapshot `COPY` / `ENV PATH` lines and before `WORKDIR`.
  - `allowed_hosts` switches `task.toml` from `network_mode = "no-network"` to
    `network_mode = "allowlist"` plus a quoted TOML `allowed_hosts = [...]` array.
    Each entry must be a bare hostname (letters, digits, dots, hyphens); anything
    else raises `ValueError` before any output is written.
  - `tests/test.sh` exports the agent change before running the visible tests:
    `cd <workdir> && git add -A && git diff --cached --binary <base> > /logs/verifier/diff.patch`.
    `<base>` is `git -C <visible>/snapshot rev-parse HEAD`, read at conversion time;
    tasks without a usable snapshot use `HEAD`. If the export fails the script
    truncates `diff.patch` and continues. Reward logic is unchanged.
  - Dockerfile and `task.toml` are byte-for-byte identical to before when both new
    options are omitted. `tests/test.sh` intentionally changes for every task
    because a run without the diff export cannot be verified.
- `factory/adapters/harbor.py`
  - `build_harbor_command(..., gateway_url=GATEWAY_BASE_URL)`; the Codex provider
    (`base_url`) and the OpenCode provider (`baseURL`) use the given URL.
- `factory/run_matrix.py`
  - New `--gateway-url` (default: `$FACTORY_GATEWAY_URL`). It is required for
    `run` unless `--dry-run`; missing or host-less URLs exit 2 with a message.
    The URL hostname is the single `allowed_hosts` entry.
  - Tasks are converted once per executor to `W/harbor/<executor>/<task_id>` with
    `to_harbor(..., executor=..., allowed_hosts=(host,))`.
  - The same URL is passed to `build_harbor_command(gateway_url=...)` and to the
    agent base-URL environment variables (`ANTHROPIC_BASE_URL` gets the root,
    `OPENAI_BASE_URL` / `OPENAI_API_BASE` get the full URL). Key env names keep
    receiving the minted key; nothing secret is logged or written.
  - The verifier argv now includes `--base-commit <snapshot HEAD>` (same
    `rev-parse` helper as `to_harbor`).
- `tests/**`
  - `to_harbor`: executor lines, allowlist TOML, host validation, diff export
    against a real snapshot commit, `HEAD` fallback, unchanged default
    Dockerfile/TOML.
  - `harbor`: Codex and OpenCode configs carry the caller's `gateway_url`.
  - `run_matrix`: one conversion per (executor, task) with the right paths and
    allowlist; verifier `--base-commit` equal to a fixture snapshot's HEAD;
    `--gateway-url` reaching the env; env default; missing URL failing clearly;
    dry run not requiring a URL.

## Verified

- `make check`: exit 0 — `718 passed, 10 xfailed in 102.26s`; ruff check, ruff
  format and all schema validations clean.
- Targeted suites: `tests/tasks/test_to_harbor.py`, `tests/adapters/test_harbor.py`
  and `tests/run_matrix` pass (70 tests).
- The snapshot commit used by `tests/test.sh` and `--base-commit` comes from a
  real temporary git repository created in the tests, not from a stub.
- The existing `run_matrix` tests still pass with a gateway URL supplied.

## Not verified

- No real Docker, Harbor or network run. The allowlist TOML and the in-container
  `git diff --cached --binary` export are exercised by generated files and local
  git, not by Harbor itself.
- No real gateway request against the URL, and no check that Harbor's network
  allowlist accepts the bare hostname form.
- Timeouts, key mint/spend/revoke and trial artifact locations remain covered by
  fakes only.

## Open questions / remaining out-of-scope items

1. **Docs contradiction.** `docs/04-executor-contract.md` says the host computes
   the diff (`compute_diff`) and `docs/05-verification-design.md` describes
   pulling `diff.patch` from the generator; the fix uses `verifier/diff.patch`.
   One document still needs updating.
2. **Spend has no real/shadow split.** `/spend` returns a single `spend_usd`;
   `run_matrix` maps it to `usd_real` and leaves `usd_shadow` at 0.
3. **Raw trial artifacts stay in `W/jobs/<run_id>/`** and are not copied into
   `runs/`.
4. **Retries leave older attempts on disk.** `check` keeps the latest attempt, but
   `load_dataset` still loads every `runs/*.json`.
